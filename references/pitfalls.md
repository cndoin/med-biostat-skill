# 已知陷阱库（pitfalls）

**动手前先扫一遍这一页。** 跨方向通用，每条都来自真实审计。
编号 P01–P25 可被脚本与报告引用（如「命中 P03 等位基因方向」）。

## B.1 数据与文件

| # | 陷阱 | 症状 | 对策 |
|---|---|---|---|
| P01 | **大分块 + 高并发导致零进展** | 跑了 30 分钟文件仍是 0 字节，进程「仍在运行」 | 分块必须小到进度可见（默认 8 MB）；加**零进展检测** |
| P02 | **截断数据被当成全量** | 只读了前 25 MB 却报「全基因组 λGC」 | 冒烟测试必须显式带 `--max-*` 且产物写 `truncated=true` |
| P03 | **等位基因方向搞反** | 跨文件合并几乎全部落空，或结果整体反向 | 用**一个具体变异实测确认**方向，不靠文档推断 |
| P04 | **染色体前缀重复** | `snp.filter` 的 `chromosome` 已带 `chr`，再加一个变 `chrchr1` | 构造键前先归一化前缀 |
| P05 | **MAF 口径混淆** | 次等位频率 vs ALT 频率直接相减，得到 0.84 的假差异 | 一律折算 `min(AF, 1-AF)` 再比 |
| P06 | **build 不一致** | GRCh37 / 38 混用，位点全部错位 | 显式声明并留转换记录 |
| P07 | **gzip 截断** | 读取时报 EOFError 或被静默截断 | `gzip -t` 校验；读取时捕获异常并报错 |

## B.2 统计与遗传

| # | 陷阱 | 症状 | 对策 |
|---|---|---|---|
| P08 | **变异数当独立位点数** | 5,882 vs 61 被当成矛盾 | 两个量都报，并按**同口径**对比 |
| P09 | **λGC 口径未声明** | 拿 A 口径的数去比 B 口径的基准 | 报口径；口径未公开时标注「不可直接互比」 |
| P10 | **可信集不过滤纯度** | 上万个 SNP 被当成一个信号 | 按 `good_cs` 过滤并记录剔除行数 |
| P11 | **用「最近基因」当区域基因** | 阳性对照假阴性 | 改用权威区间注释 |
| P12 | **窗口宽度决定结论** | 换窗口结论就变 | 窗口预设 + 敏感性矩阵 |
| P13 | **效应量直接外推** | 发现期效应量被当成真实效应 | 外部复现后再引用 |
| P14 | **共享对照当独立证据** | 两个端点对照数相同却做 meta | 检测对照数；**不可合并** |
| P15 | **共病混杂当成发现** | 最强位点其实是另一疾病的位点 | 与其他疾病做**变异级距离比对** |
| P16 | **只报 AUROC** | 预测模型无校准与 DCA | 三件套齐（区分度+校准度+决策曲线） |
| P17 | **检验方法不由数据决定** | 默认 t 检验，忽略分布 | 正态性检验决定方法 |
| P18 | **多重检验不校正** | 只报名义 P<0.05 | BH-FDR + 主结论 Bonferroni，并报检验次数 |

## B.3 工程与流程

| # | 陷阱 | 症状 | 对策 |
|---|---|---|---|
| P19 | **静默失败** | 脚本正常退出，但输出是错的 | 关键步骤加断言与零进展检测；**「全绿」不等于「对」** |
| P20 | **含数字的报告被「重写」** | 写作代理顺手把数字改了 | 确定性转换，禁止改写 |
| P21 | **同一逻辑多处实现** | 同一句话在不同模块得到不同结论 | 抽**唯一裁决点**，其他模块委托 |
| P22 | **验证脚本硬编码期望值** | 升版后变成假失败 | 从 VERSION 文件或产物读期望值 |
| P23 | **测试只测「该报警的场景」** | 检测器靠无脑报警就能满分 | 必须造**反向样本**测假阳性 |
| P24 | **门禁没被证明会失败** | 分不清「门禁有效」和「门禁是摆设」 | 删文件 / 改配置看是否报 FAIL |
| P25 | **环境依赖漂移** | 某天某包突然不见了（如 click） | 锁版本 + 幂等安装脚本 + 环境自检 |

## 使用方式

- S0 完成后、进入 S1 之前：扫一遍全表，把与本项目相关的记进 `logs/00_intake.json`。
- 每次输出指标前：对照 P08/P09/P10/P16/P18（口径与统计类）。
- 每次写完脚本：对照 P19–P25（工程类）。
