# 数据源清单（data_sources）

## 分级与使用规则

| 层级 | 定义 | 例子 | 使用规则 |
|---|---|---|---|
| **一级** | 国家队列 / 国际联盟的官方发布，有版本号与哈希可校验 | FinnGen、GTEx、UKB-PPP、1000G | 可直接作主数据源 |
| **二级** | 领域公认的整合数据库 | GWAS Catalog、OpenGWAS、eQTL Catalogue、mygene.info | 作主源须说明其上游来源；作补充 / 验证可直接用 |
| **三级** | 文献附带资源 | 论文补充数据的 eQTL 矩阵 | **不能作核心暴露**，除非先落实可获取性与版本 |

## 版本与时效性检查清单（每次立项前必过）

- [ ] 该源**当前最新公开版本**是什么？（不要沿用上次记录的版本）
- [ ] 最新版是否为**无条件公开**，还是需要申请 / DAC？
- [ ] 新旧版本的 **URL 路径结构**是否一致？（R12 与 R13 就不同）
- [ ] 最新版的**样本量 / 病例数 / 端点数**变化是否影响既定设计？
- [ ] 最新版是否**新增了此前不存在的端点**？（R13 新增青少年型与先天性白内障）
- [ ] 换版本的代价（下游全部重跑）是否可接受？**要么现在切、要么明确锁定旧版并写清理由**。

## 取回四条硬要求（S1②）

1. **分块并行**（默认 8 MB/块，8–24 并发）。小分块是硬要求。
2. **断点续传**：每块独立文件，已完整块直接复用。
3. **限速绕开**：先测单连接吞吐，再用并发数决定聚合吞吐。
4. **上限保护**：冒烟测试必须显式带 `--max-*`，产物写 `truncated=true`。

## 完整性五道核验（S1③，强度递增）

1. 字节数 == 官方 `Content-Length`
2. 压缩完整性（`gzip -t`）
3. 哈希对照（官方 md5/sha256；GCS 可从 `x-goog-hash` 取）
4. **两套官方产物逐变异互证**
5. 等位基因方向与 build 一致性检查
