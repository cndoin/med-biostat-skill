# 报告规范与期刊硬指标（reporting_standards）

## 按研究类型对表

| 研究类型 | 报告规范 | 关键必填项 |
|---|---|---|
| 观察性研究 | **STROBE** | 参与者流程、缺失数据、偏倚讨论 |
| 孟德尔随机化 | **STROBE-MR** | 工具变量假设、多效性检验、Steiger |
| 预测模型 | **TRIPOD+AI** | 区分度 + 校准度 + 决策曲线 + 验证 |
| 系统综述 / Meta | **PRISMA** | 检索式、筛选流程、异质性 |
| 遗传关联 | STREGA / GWAS 报告清单 | 位点定义、λGC 口径、多重检验 |

规范索引入口：EQUATOR Network。

## 期刊硬指标（眼科，实测）

> 来源：Science Editing 2026;13(2):139-145（按 2024 SJR 取前 50 本眼科期刊）。

| 指标 | 数值 |
|---|---|
| 主图上限（中位） | **6 张**（仅 24% 期刊规定插图上限） |
| 正文词数（中位） | 4,000 词 |
| 摘要（中位） | 250 词 |

## 图表纪律（S6）

- 主图 **4–8 张**，每张推进一层论证；**不堆图**。
- 图必须能由脚本重跑得到；附 source data。
- 矢量优先（SVG / PDF）；位图仅用于必要场景。

## 可重算性（S6）

- 任何一张图的数字都能由脚本重跑得到。
- 交付物附 `logs/`（判定记录）、`tables/`（source data）、`scripts/`（代码）。
- 代码标识：DOI / Zenodo / GitHub commit hash。

## 写作与投稿定位（S6）

按**「新机制 + 独立验证层 + 数据规模」三要素**定档：

| 档 | 要求 |
|---|---|
| 高影响力刊 | 新机制 + 独立验证层 + 大规模数据 |
| 中档 | 独立验证层 + 中等规模，或新机制初步证据 |
| 方法学刊 | 方法创新本身即卖点，**不投要求新机制的刊** |

**不要把方法学工作投到要求新机制的刊。**

## 确定性文档流水线（S7 硬约束）

```
内容 Markdown → 模板 HTML → 质量门禁 → DOCX
```

**含数字的报告绝不能让写作代理改写。** 必须走确定性转换，否则数字会被「顺手改对」。
实现：`scripts/report_pipeline.py` + `assets/html_template/` + `assets/report_contracts/`。
