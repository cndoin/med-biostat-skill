# 混杂与偏倚十二项（confounders）

**混杂是主战场，不是注意事项。** 生信分析翻车绝大多数不在算法，在混杂。
本层是独立一层（S4），十二项**逐条过**，每项给可执行检测手段。

**输出**：`logs/confounder_audit.json` + 一张「哪几项已查、结论是什么、哪几项无法查及原因」的表。
**无法查的必须写「无法查」，不能写「未见异常」。**

| # | 混杂项 | 可执行检测手段 | 实证案例 |
|---|---|---|---|
| 1 | **群体分层** | λGC、QQ、PC 数；奠基者人群的外推限制须声明 | 芬兰奠基者人群，效应量不可直接移植 |
| 2 | **年龄与性别** | 核对协变量清单、是否仅线性项；查有无分层端点可做交互 | 官方 SAIGE 协变量为 age / sex / 10 PCs / batch，年龄仅线性项 |
| 3 | **样本重叠** | **比对端点间对照数**；共享对照则不得当独立证据合并 | 两个白内障端点对照数完全相同（409,535） |
| 4 | **共病与转诊** | **与其他疾病的位点做变异级距离比对** | chr15:73,931,230 与剥脱综合征青光眼是同一变异（0 kb） |
| 5 | **表型界定** | 编码体系、检测偏倚、竞争风险 | 更常就医者更易被记录到编码 |
| 6 | **效应量膨胀** | 发现期效应量不得外推，须外部复现后再引用 | 位点表 P 与 beta 来自同一发现阶段 |
| 7 | **组织错配** | 暴露组织 vs 病变部位一致性检查 | 视网膜 QTL ≠ 晶状体 |
| 8 | **多重检验** | 报检验次数；BH-FDR + 主结论 Bonferroni | 41 区域 × 54 组织 = 2,214 次检验 |
| 9 | **窗口与阈值** | 所有窗口 / 阈值预设并做敏感性矩阵 | ±1.5 Mb 窗口 → 每区域中位 58 基因（16–145） |
| 10 | **技术性伪影** | INFO / MAF / MAC、批次、基因型质量 | — |
| 11 | **信息偏倚** | 缺失机制、测量误差、回归稀释 | — |
| 12 | **研究者自由度** | 判定门前置；禁止事后更换口径 | 「为省时间截断数据」是全部错误的上游 |

## 每项的判定输出格式

```json
{
  "id": 4,
  "name": "共病与转诊",
  "status": "checked",            // checked | partial | cannot_check
  "evidence": "chr15:73,931,230 与 XFS 青光眼位点距离 0 kb",
  "conclusion": "最强信号实为共病位点，不得作为白内障新发现",
  "artifacts": ["tables/comorbidity_distance.tsv"]
}
```

- `status=cannot_check` 时必须写 `reason`（缺哪个数据、为什么拿不到）。
- **禁止**用 `"未见异常"` 代替 `cannot_check`。

## 自动化检测（`scripts/confounder_audit.py`）

脚本对能自动判定的项做机器检查，其余项输出 `status="manual_required"` 并给出所需输入：

| 可自动判定 | 依赖输入 |
|---|---|
| #1 λGC 与 QQ 分位点 | GWAS 汇总统计 |
| #3 样本重叠 | 端点清单（含对照数） |
| #4 共病距离比对 | 本方向位点表 + 对照疾病位点表 |
| #8 多重检验计数 | 分析配置（区域数 × 组织数） |
| #9 窗口敏感性矩阵 | 位点计数结果（多窗口） |
