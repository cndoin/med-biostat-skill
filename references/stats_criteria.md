# 统计判据（stats_criteria）

## 遗传关联（S3①）

- **独立位点识别**：**LD 聚类优先**（需 LD 参考）；退化方案是距离聚类，必须报窗口并做敏感性。
  自建口径与已发表口径的偏差要**显式量化**（实证：自写距离聚类与官方 `num_gw_significant` 相差 12–19%，混合口径无法归因）。
- **精细定位**：可信集须按**纯度过滤**（`good_cs`），低纯度大可信集必须剔除并记录剔除行数
  （实证：存在 `cs_size` 达 21,398 的低纯度可信集，不过滤会污染全部下游）。
- **位点-基因归属**：**区间注释优先**。`最近基因` 字段不能当「区域基因」用（会造成阳性对照假阴性）。

## 因果推断（S3②）

- 两样本 MR：**F 统计量 > 10**、**Steiger 方向正确**、多效性检验（MR-PRESSO / Egger 截距）、异质性。
- 共定位：**PP.H4 > 0.8 为主判据**（比 MR 的 P 值更稳）。
- **组织错配必须显式声明**：暴露组织与病变部位不一致时，只能作为局限承认真实，不能通过写作绕开。

## 组学整合（S3③）

- eQTL/pQTL 映射与 TWAS/PWAS。
- **组织富集**：主结论用**分层 LD 分数回归（LDSC-SEG）**：
  前 10% 特异表达基因（SEG）+ 转录区两侧 100 kb 构建注释 + 联合模型纳入「全部基因」与 52 个基线注释。
  Fisher + 置换**降级为描述性结果**，并必须同时报告窗口敏感性。
  **DEPICT 式固定阈值法与无协变量的 MAGMA 列入红线，禁止使用。**
- 组织特异性：**表达广度 + τ 指数双指标**，避免单一指标的边界效应。
- **窗口敏感性**：基因归属窗口越宽，真实信号被稀释越严重。窗口须预设并做换窗口敏感性。
- 单细胞归属：细胞类型层级用 sc-linker 的 **τ\***（跨注释大小可比）。

## 临床统计（S3④）

- 描述：**检验方法由正态性检验决定**，不能默认 t 检验。
- 组间比较：**效应量 + 置信区间 + p 值三件齐全**。
- 生存：比例风险假定检验、竞争风险、landmark 分析避免永生时间偏倚。
- 预测模型：**区分度 + 校准度 + 决策曲线三件齐**，嵌套交叉验证防泄漏。**只报 AUROC 视为红旗**。
- 亚组与交互：**交互检验**而非分组比较。

## 差异性检验选择表

| 场景 | 正态 | 非正态 |
|---|---|---|
| 两组独立 | Welch t | Mann-Whitney U |
| 两组配对 | 配对 t | Wilcoxon 符号秩 |
| 多组独立 | ANOVA + 事后 | Kruskal-Wallis + Dunn |
| 分类关联 | — | 卡方 / Fisher 精确 |
| 生存比较 | — | Log-rank + Cox（PH 假定检验） |

## 多重检验

- 报**检验次数**；**BH-FDR** 用于探索性，**Bonferroni** 用于主结论。
- 主结论必须同时给名义 P 与校正后 P。

## 模型三件套（预测模型）

| 件 | 指标 | 要求 |
|---|---|---|
| 区分度 | AUROC / C-index | 必报 |
| 校准度 | 校准曲线 / 校准斜率 / Brier | 必报 |
| 决策曲线 | DCA 净收益 | 必报 |
| 验证 | 嵌套交叉验证 / 外部验证 | 防泄漏 |
